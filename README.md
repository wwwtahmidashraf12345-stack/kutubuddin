# মারকাযুল হক মুন্সিগঞ্জ (চাম্পাতলা মাদরাসা) — কালেকশন অ্যাপ (MERN)

MongoDB + Express + React (Vite) + Node। একটাই সার্ভার API ও পেজ দুটোই দেয়।
লগইন ছাড়া কিছু দেখা যায় না। **অ্যাডমিন** = এন্ট্রি/এডিট/এসএমএস, **দর্শক** = শুধু দেখা।

## ফোল্ডার
- `server/` — Express API, মডেল (`models.js`), এসএমএস গেটওয়ে (`sms.js`), প্রথম ইউজার বানানোর `seed.js`
- `client/` — React অ্যাপ (আজ/সপ্তাহ/মাস/হিস্ট্রি, সদস্য, প্রোফাইল, ১২ মাসের তালিকা)
- `madrasa-excel-template.xlsx` — নতুন সদস্য এক্সেলে লেখার ফাইল

## চালানোর ধাপ (কম্পিউটারে)
1. Node.js 18+ ও একটি MongoDB লাগবে। সহজ উপায়: mongodb.com/atlas-এ ফ্রি ক্লাস্টার খুলে কানেকশন লিংক নিন
   (Network Access-এ আপনার আইপি বা সার্ভারের আইপি অনুমোদন দিন)।
2. `server/.env.example` কপি করে `server/.env` নাম দিন; `MONGODB_URI` ও লম্বা একটা `JWT_SECRET` বসান।
3. প্রজেক্টের ফোল্ডারে: `npm install` তারপর `npm run install:all`
4. প্রথম অ্যাডমিন: `npm run seed --prefix server -- আপনার@ইমেইল.com পাসওয়ার্ড admin`
   দর্শক বানাতে শেষে `viewer` দিন।
5. `npm run dev` — ব্রাউজারে http://localhost:5173 খুলুন।

## অনলাইনে দিতে (Render / Railway ইত্যাদি)
- Build: `npm run install:all && npm run build`   Start: `npm start`
- Environment-এ `MONGODB_URI`, `JWT_SECRET` (এবং এসএমএস ভ্যারিয়েবল) দিন।
- তৈরি হওয়া লিংকটাই সবাইকে দিন। ফোনে খুলে "Add to Home screen" দিন।

## এসএমএস (গেটওয়ে থেকে কাটবে)
নতুন দান সংরক্ষণ হলেই সার্ভার গেটওয়ে দিয়ে সদস্যের নম্বরে পাঠায়। গেটওয়ে যোগ করতে শুধু `server/.env`-এ:
`SMS_GATEWAY_URL` (নম্বরের জায়গায় `{to}`, বার্তার জায়গায় `{message}`), দরকার হলে `SMS_SUCCESS_MATCH`,
`SMS_NUMBER_FORMAT`, POST হলে `SMS_METHOD`/`SMS_BODY`/`SMS_CONTENT_TYPE`। উদাহরণ `.env.example`-এ আছে (গেটওয়ের ডক দেখে মিলিয়ে নিন)।
গেটওয়ে না থাকলে বা ব্যর্থ হলে দান ঠিকই সংরক্ষিত হয়, আর বার্তা কপি/ফোনের মেসেজ অ্যাপে খোলার বক্স আসে।
প্রতিটি পাঠানোর ফলাফল `smslogs` কালেকশনে থাকে। সংশোধনে নতুন এসএমএস যায় না; এন্ট্রি খুলে "এসএমএস" চেপে আবার পাঠানো যায়।

## এক্সেল থেকে নতুন সদস্য
সদস্য ট্যাবে (অ্যাডমিন) "এক্সেল থেকে নতুন সদস্য যোগ" → ফাইল বাছুন। সদস্য নং ফাঁকা থাকলে নিজে বসে;
আগে থাকা সদস্য (একই নাম+মোবাইল বা একই নং) বাদ যায়।
